# Рядок за рядком

Тренажер англійської через улюблені пісні: урок по одному рядку (слова, вибір перекладу, на слух, збери рядок, закінчення слова, пропуски, весь рядок з пам'яті, спів у мікрофон) і караоке-режим, де пісня зупиняється на кожному рядку, поки не впишеш пропущене слово.

- Текст з часом для рядків: [LRCLIB](https://lrclib.net) (завантажується в браузері користувача, у репозиторії текстів пісень немає).
- Звук: вбудований плеєр YouTube.
- Прогрес зберігається в браузері (localStorage).
- Переклад: через чат з ШІ (копіюєш запит) або власний ключ Claude API, який лишається тільки в браузері.

Один файл `index.html`, без збірки. Хостинг: GitHub Pages.
